A short field guide

Git keeps a record
of how work changes.

Git is a version control system. It lets a developer save named snapshots of a project, compare edits, and return to an earlier state when needed.

The three places to know

Working tree: the files you are currently editing. Git reports edits here as modified, and new files as untracked.

Staging area: the changes selected for your next snapshot. git add moves changes here.

Repository: the saved project history. git commit records what is staged with a message describing the change.

A useful routine is to check git status, inspect edits with git diff, stage the intended files, review the staged diff, and commit.
